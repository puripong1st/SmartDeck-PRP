# Local Web UI

This app will contain the SmartDeck Pro Local Web UI.

Planned stack:

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

Primary responsibilities:

- Profile editor
- Device page and 3 by 4 button grid editor
- Built-in action configuration
- Macro Builder
- Asset upload and preview
- App Detection Rule management
- Firmware status and manual update flow
- Bridge Pairing UI
