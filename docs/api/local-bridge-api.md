# Local Bridge API

The Local Bridge API is the localhost-only HTTP and WebSocket API used by the Local Web UI to access local capabilities.

## Base Rules

- Bind only to `127.0.0.1`.
- Require Bridge Pairing before privileged use.
- Require a pairing token on every request after pairing.
- Restrict CORS to allowed local origins.
- Never expose the API on LAN or the public internet in the MVP.

## HTTP Areas

```text
GET    /health
POST   /pairing/start
POST   /pairing/confirm
POST   /pairing/revoke

GET    /devices
GET    /devices/:deviceId
POST   /devices/:deviceId/sync

GET    /profiles
POST   /profiles
GET    /profiles/:profileId
PUT    /profiles/:profileId
DELETE /profiles/:profileId

GET    /actions/registry
POST   /actions/execute

GET    /assets
POST   /assets
GET    /assets/:assetId
DELETE /assets/:assetId

GET    /app-detection/rules
POST   /app-detection/rules
PUT    /app-detection/rules/:ruleId
DELETE /app-detection/rules/:ruleId

GET    /firmware/status
POST   /firmware/update
```

## WebSocket Areas

```text
ws://127.0.0.1:<port>/events
```

Event stream uses SmartDeck Protocol envelopes for:

- device connection changes
- active profile changes
- button events
- action execution results
- widget updates
- firmware update progress
- bridge diagnostics

## Pairing Token

The pairing token is a local secret generated by the Local Bridge. It is not a cloud login token and must not be treated as an account identity.

## Execution Logging

The Local Bridge should record basic local logs for action execution, profile switching, firmware updates, and pairing changes. These logs are for local troubleshooting, not enterprise audit.
